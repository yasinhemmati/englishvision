📦 فرمت و حجم
──────────────

• فرمت: JPG (برای عکس‌های واقعی) یا PNG (برای آیکون با شفافیت)
• حجم: ترجیحاً زیر ۵۰ کیلوبایت برای هر تصویر
• کیفیت: نسبت سرعت/کیفیت در JPG = ۸۰٪
• اگر هم بزرگ‌تره مشکلی نیست — سایت با CSS اندازه‌اش رو تنظیم می‌کنه

🔄 سیستم نمایش
──────────────

سیستم تصاویر چند تا قابلیت داره:

۱. **Lazy-load**: فقط وقتی کاربر اسکرول کنه و عکس داخل دید بیاد، بارگذاری می‌شه
۲. **Skeleton loader**: تا قبل از بارگذاری، یه انیمیشن لرزش نشون داده می‌شه
۳. **Error handling**: اگه فایل پیدا نشه، یه پیام مودبانه نشون می‌ده با نام فایل مورد نیاز
۴. **Responsive**: سایز خودکار بر اساس صفحه نمایش
۵. **Caption**: می‌شه زیر هر عکس متن اضافه کرد

📝 نام‌گذاری فایل‌ها
───────────────────

قوانین:
• فقط حروف کوچک (lowercase)
• فاصله‌ها به خط تیره (-) تبدیل بشن
• اسلش (/) هم به خط تیره
• علامت‌های دیگه (آپاستروف، کاما) حذف بشن

مثال:
  "Pencil Case"  →  pencil-case.jpg
  "T-shirt"      →  t-shirt.jpg
  "flat/apartment" → flat-apartment.jpg
  "2 o'clock"    →  2-oclock.jpg
